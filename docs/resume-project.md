# Brace Map Chat 项目介绍

## 项目概述

Brace Map Chat 是一款面向深度学习场景的树状会话工具。它将传统线性聊天拆分为横向生长的可视化学习树：每个节点保存一段独立的多轮会话，用户可从原文中摘录疑问、创建子分支，并在不丢失主线进度的情况下继续探索知识细节。

## 核心功能

- 基于画布组织多主题、多层级会话，支持节点展开、折叠、拖动、纵向缩放和贝塞尔曲线连接。
- 支持字符级、跨段及跨消息摘录，并以“父节点摘要、选中原文、用户问题”创建独立上下文分支。
- 提供全局学习 Agent，可通过多轮对话规划学习目标、章节及必要的二级结构，并在用户审核后管理学习树。
- 接入 OpenAI Responses API 与 Anthropic Messages API，支持兼容服务地址、模型发现、流式输出、中止及重新生成。
- 使用 SQLite 持久化画布、消息、笔记、摘要和 Agent 会话，支持事务化导入导出、版本冲突检测、单实例进程锁和浏览器编辑租约。
- 提供 Markdown 消息渲染、完整会话模式、长消息编辑器，以及单元、数据层和浏览器端到端测试。

## 技术栈

React 19、TypeScript、Vite、React Flow、Node.js、SQLite、SSE/NDJSON、Playwright、Node Test Runner、Oxlint。

## 工程亮点

- 将不同模型供应商的请求与流事件归一化，前端只处理统一的增量消息协议。
- 针对流中断、缺失终止事件、重复生成和部分回答设计了明确的状态与恢复路径。
- 通过 SQLite 事务、乐观版本控制、进程单实例和页面编辑租约共同避免多端覆盖学习数据。
- 对大型学习树采用渐进展示、自动布局与碰撞处理，减少节点集中堆叠并改善画布交互性能。
- 当前具备 68 项服务端与数据层测试、28 项浏览器端到端测试。
