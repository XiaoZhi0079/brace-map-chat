# Brace Map Chat：当前产品说明

## 产品目标

Brace Map Chat 把一个长期学习主题组织成横向生长的会话树。每个节点是一段独立多轮会话；用户可以把局部疑问建立为子节点，在不打断主线的情况下深入讨论。

## 当前技术

- TypeScript、React、Vite；
- `@xyflow/react` 负责画布、节点拖动、缩放和贝塞尔连线；
- 本地服务端 SQLite 保存画布、节点会话、布局、全局 Agent 会话、审核卡和 Agent 规划会话；
- Vite 同源服务端中间件保存模型配置并代理模型请求；
- 支持 OpenAI Responses API 与 Anthropic Messages API，两种协议均允许自定义请求地址；
- 当前不包含账户、云同步或多人协作。
- 同一项目目录只允许一个正式服务进程运行；第二端口启动时会显示当前实例地址并退出。
- 同一服务只允许一个浏览器页面持有编辑租约，其他页面等待原页面关闭后自动重试。

## 画布与节点

- 一个画布对应一个学习主题和一棵单根树；
- 节点严格单父、多子，不支持跨分支关系线；
- 节点默认显示可编辑标题，展开后为约 `640 × 400px` 的普通会话窗口；
- 用户消息在右侧，AI 消息在左侧；
- 节点消息可以逐条编辑或删除，也可以清空完整会话；
- 普通节点按增量流式显示模型回答；每个节点拥有独立的中止控制，停止后保留部分正文并标记状态；
- 删除节点会连同后代一起删除；
- 节点标题、简介、学习摘要与个人笔记是不同字段。

节点不是 Agent。节点请求只携带本节点自己的标题、简介、冻结初始上下文和消息，不能动态读取其他节点。

## 分支上下文

创建普通子分支使用三段式上下文：

1. 完整父节点会话形成的背景摘要；
2. 用户通过字符级拖拽摘录选中的原文；
3. 用户真正想追问的问题。

三段内容在创建时冻结，成为新节点自己的上下文。详细方案见[子会话上下文摘要](context-summary-options.md)和[交互 Demo 说明](context-branch-demo.md)。

## 学习摘要

- 每个节点只有一份当前学习摘要；
- 摘要必须由用户在节点内手动触发；
- 生成时读取该节点完整会话，不按最近轮次截断；
- 用户可以编辑结果；
- 消息变化后摘要标记为过期；
- 全局 Agent 不能根据树目录直接改写学习摘要。

## Agent 初始化

新建画布时可以自主创建，也可以让全局 Agent 初始化：

1. Agent 先通过对话明确主题和目标成果；
2. 主题或目标缺失时，Agent 明确列出还需确认的内容；信息充分后出现“生成结构草稿”，且该状态在用户继续补充要求时保持；用户明确提出生成也会得到确定性的确认按钮，但不会自动创建；只有明确更换主题或目标范围才重新确认；
3. 草稿包含总目标、3 到 7 个主要章节，以及必要时少量二级章节；
4. Agent 在生成时解释章节边界、学习顺序、拆分粒度和目标匹配度；用户满意时可以直接采用，不强制追加一次模型自评；
5. 用户可以继续用自然语言修改，也可以直接编辑、增删和排序；
6. Agent 必须评价用户建议是否中肯、说明取舍和风险，不能默认赞同；评价结果作为独立调整稿，不能直接覆盖当前方案；
7. 用户可以接受调整、保留原方案或继续提出异议；手动修改需要 Agent 评价，但失败请求不能进入对话上下文；
8. 用户采用后才创建正式画布；
9. 采用后立即为总目标生成整门学习的老师式开场；章节保留各自开场提示，第一次展开且会话仍为空时才生成，避免初始化阶段集中请求模型。

初始化规划按独立会话持久化，而不是只保留一份草稿：

- 可以新建、继续、重命名和删除多条规划会话；
- 新建画布窗口显示最近 3 条未完成规划，并可进入全部会话列表；
- 全部列表按更新时间倒序，分为“未完成”和“已创建画布”；
- 采用规划后保留只读对话、最终结构和调整记录，并关联所生成画布；删除规划记录不会删除画布；
- 自主创建画布不删除规划；旧版单份草稿自动迁移为一条会话；
- 第一版不提供搜索、标签、文件夹或归档。

正式采用以后，Agent 不自动重排、移动或删除已经使用的学习路径。

## 全局 Agent

系统始终只有一个能力一致的全局 Agent。切换画布只是切换它查看的工作区。

全局 Agent 可以：

- 读取整棵树的结构化目录；
- 按需读取一个节点的完整会话；
- 提议创建子节点；
- 提议修改标题、简介和学习状态；
- 对指定节点执行主题巡检；
- 巡检分支引用真实消息，把必要背景、原文和问题冻结到新节点；
- 在审核后重新读取最新画布并核对任务结果。

所有树修改都要用户审核，并绑定提案生成时的画布版本。完整循环和状态约束见[全局学习树 Agent 设计](agent-design.md)。

## Agent 命令

- `/model`：切换全局 Agent 使用的配置或模型；
- `/resume`：新建、恢复或删除当前画布下的 Agent 会话；
- `/inspect`：选择一个节点执行主题巡检。

命令支持唯一前缀识别，例如 `/re` 解析为 `/resume`。

## 当前明确不做

- 节点自行读取其他节点；
- 为每个节点创建持久化 Agent；
- 持续后台巡检和巡检游标；
- 自动判断节点会话结束并生成摘要；
- 正式学习开始后的自动重排；
- 前置关系、关联关系和引用连线；
- 未经审核的树修改；
- 登录、云同步和多人协作。

## 本地数据

- 画布、节点、消息、布局与两类 Agent 会话：本地服务端 `.data/brace-map-chat.sqlite`；
- 模型配置与密钥：本地服务端 `.data/model-profiles.json`；
- 服务诊断日志：本地服务端 `.data/logs/brace-map-chat-YYYY-MM-DD.jsonl`，可用 `LOG_DIRECTORY` 修改目录；
- API Key 不下发到浏览器，也不写入浏览器存储。
- 日志记录请求 ID、协议、模型、上游地址、耗时和流式终态，但会脱敏密钥、提示词、消息正文和请求体；页面错误同时显示请求 ID，便于对应日志。
- 旧版浏览器数据只作为一次性迁移源；服务端事务提交成功后才清除旧键。

设置面板支持导出和导入版本化学习数据备份：

- 包含画布、节点、消息、摘要、笔记、全局 Agent 会话和 Agent 规划会话；
- 兼容仅含单份初始化草稿的旧备份，导入时自动迁移；
- 不包含模型配置、模型选择和 API Key；
- 导入前完整校验树结构和嵌套内容，不能部分导入；
- 用户确认后在 SQLite 事务中整体替换学习数据，任一写入失败都会回滚；
- 导入后当前页面立即切换到备份中的活动画布，无需刷新。

公开部署前需要增加账户、权限、配额、租户数据隔离和正式的密钥管理。

## 自动化检查

除服务端和数据校验单元测试外，Playwright 端到端测试覆盖单浏览器编辑租约、流式增量、中止与请求 ID、旧版顶级开场迁移、半句/反向/多次摘录、初始化评审门槛、草稿恢复、备份导入导出、无效备份保护、`/resume`、`/model`、`/inspect`、巡检真实依据和画布版本冲突。SQLite 测试直接覆盖 v1→v2 迁移、旧版本写入冲突、跨画布重复 ID、级联删除和未完整回答状态；启动测试覆盖跨端口项目锁和陈旧锁回收；日志测试验证按日写入和敏感字段脱敏。
