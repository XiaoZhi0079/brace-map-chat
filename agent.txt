学习知识树 Agent 当前职责

系统只有一个全局学习树 Agent。画布是它当前查看的工作区；普通节点只是彼此隔离的会话窗口，不是 Agent，也不能读取其他节点。

1. 初始化学习树

Agent 与用户明确学习主题和目标成果后，生成一个总目标节点、3 到 7 个主要章节；过于宽泛的主要章节可以在草稿阶段附带少量二级章节。Agent 必须在生成时解释章节边界、学习顺序、拆分粒度和目标匹配度；用户满意时可以直接采用。用户提出修改或直接编辑后，Agent 需要评价建议是否中肯、说明取舍和风险，不能默认赞同，并返回一份待确认调整方案。原方案在用户接受调整前保持不变；用户可以接受调整、保留原方案或继续提出异议，最终采用后才创建正式画布。

2. 理解全局状态

Agent 先读取学习目标、树结构、节点标题、简介、状态、学习摘要和消息数量。只有这些信息不足时，才指定并读取某个节点的完整会话。不能直接加载整棵树的全部历史。

3. 管理知识结构

Agent 可以提议创建子节点、修改节点标题、修改简介和学习状态。所有修改必须经过用户审核，并校验画布版本。Agent 不直接删除、移动、重排节点，也不建立前置或关联关系。

4. 主题巡检

用户可以让 Agent 检查指定节点。Agent 读取该节点完整会话；短暂类比和辅助说明不算偏题。只有出现值得独立多轮学习的新方向时，Agent 才提议创建子分支。建议必须引用真实消息，并展示必要背景、原会话依据和分支问题；用户接受后这些内容冻结到新节点。节点自身不承担巡检。

5. 固定工作循环

一次任务最多自动执行 4 步。每一步只能选择：读取一个节点、提交操作等待审核、明确结束。审核完成后，Agent 重新读取最新画布并判断任务是否完成。达到目标、无需修改、需要用户决定或达到步骤上限时停止。

6. 摘要边界

节点学习摘要由用户在节点内手动授权生成，并读取该节点完整会话。全局 Agent 可以指出摘要缺失或过期，但不能仅凭树目录改写学习摘要。

7. 恢复

/resume 恢复当前画布的 Agent 会话和审核卡。单次运行的步骤号、读取内容和巡检游标不持久化；刷新中断后从最新树摘要重新执行，避免积累不可见状态。
